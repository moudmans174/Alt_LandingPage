# Chatter – Landing Page

HTML & CSS build of the Chatter landing page from the Figma design
(AI-Powered FullStack, Karatu 2026 First Semester project exam).

## Features
- Semantic HTML5, plain CSS (no frameworks, no JavaScript)
- Pixel-matched to the 1440px Figma frame (DM Sans, brand colour `#543EE0`)
- Fully responsive: desktop, tablet and phone, with a CSS-only hamburger menu

## Run locally
Open `index.html` in any browser.

## Structure
```
index.html   – page markup
style.css    – all styles
```
